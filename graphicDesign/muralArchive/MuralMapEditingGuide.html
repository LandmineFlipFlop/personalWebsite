Mural Map Editing Guide

How to add a new mural:

At the end of the mural section add this block of text if you don't have name credits yet:

<div  class="container" style="top: [X]vw; left: [Y]vw;">

    <a style=" height: 2.3vw;" class="selection"

       onclick="modalScript('[name]:\n'

       + '⠀⠀year: [year]\n'

       + '⠀⠀credits: undocumented', 'images/[full]',

        [extra],

        [link], [text])"

    ></a>

    <img class="photo" src="previews/[preview]" alt=""/>

</div>

If you do have names add this instead:

<div  class="container" style="top: [X]vw; left: [Y]vw;">

    <a style=" height: 2.3vw;" class="selection"

       onclick="modalScript('[name]:\n'

       + '⠀⠀year: [year]\n'

       + '⠀⠀credits:\n'

       + '⠀⠀⠀⠀• [name first]\n'

       + '⠀⠀⠀⠀• [name second]\n'

       + '⠀⠀⠀⠀• [name etc...]\n'

       + '⠀⠀⠀⠀• [name last]', 'images/[full]',

        '[extra]',

        '[link]', '[text]')"

    ></a>

    <img class="photo" src="previews/[preview]" alt=""/>

</div>

If you want to edit an existing mural you can instead find it in the main section of the HTML and update as needed.

Color label breakdown:

  • Position on screen, play around with values till it's where you want. You can reference the position of other murals when adding a new one
  • Use this if it’s a tall image, otherwise omit this section.
  • This is the mural name displayed when you click on it, add a descriptive name if none is given.
  • The best estimate for the mural year of creation, if unknown then just put undocumented in place of it
  • The file names for the full and preview images respectively
  • preferably file names should be camelCase, and the the file-type should be either jpg or png format
  • the preview image (the one you see on hover) should be in the previews folder and should be minimal in file size (probably jpg)
  • the full image (the one you see once clicked) goes in the images folder and should be high quality (png, or less optimized jpg)
  • An optional poster history/additional information section (omit this if you don’t need it, but if there's a link section you can instead just fill it in as:  , '',  )
  • An optional link (omit this section if you don’t need it) write the URL in the first section, and its label in the latter.
  • Add as many names as you need following the pattern that's shown above, if there is only one name, just use:  [name last]
  • There are a few things you need special text notation for since some characters already have a specific meaning in javascript or html. for those you can reference Javascript Escape Characters
